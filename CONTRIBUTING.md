## Contributing to rcards

Thank you for your interest in contributing to the rcards project! We welcome contributions of all kinds, including bug reports, feature requests, code improvements and documentation updates.

### How to Contribute

1. **Fork the repository** and create your branch from `main`.
2. **Write clear, concise code** and follow the style of the existing codebase.
3. **Add tests** for new features or bug fixes when appropriate.
4. **Document your changes** in code comments and update relevant documentation files.
5. **Submit a pull request** with a clear description of your changes and reference any related issues.

### Code of Conduct

Please review and follow our [Code of Conduct](CODE_OF_CONDUCT.md) to ensure a welcoming and respectful environment for all contributors.

### Reporting Issues

If you find a bug or have a feature request, please open an issue with detailed information to help us address it effectively.
